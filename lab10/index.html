4. Design Reflection (Part E)

I extended my Lab 9 geospatial visualization comparing 2025 nominal GDP across a choropleth map and a Dorling cartogram by integrating browser-based voice interaction via the Web Speech API. The voice interface supports three primary visual exploration tasks: filtering economies by continental region or rank tier (e.g., "Show Asia", "Show Top 10"), locating and highlighting specific nations across both coordinated views (e.g., "Highlight Singapore"), and resetting the viewport ("Reset").

Voice interaction is suitable for this dual-map visualization because compact high-GDP economies like Singapore, Switzerland, or Ireland occupy minuscule geographic polygons on the choropleth. These make them not very easy to hunt down and click manually. Speaking a country's name directly bypasses spatial search friction, immediately cross-highlighting both its geographic boundary and its inflated cartogram bubble while zooming the map.

During testing, I observed several limitations: background noise and pronunciation variations occasionally caused homophone transcription errors and the Web Speech API lacks uniform support across all browsers. To mitigate these issues, I implemented fuzzy keyword matching, clear visual transcript and status feedback, explicit click-to-listen microphone activation for privacy and conventional dropdown and button fallback controls.
