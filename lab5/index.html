1. Dataset Description

This dataset represents a synthetic urban transit network with 50 stations and 50 direct undirected connections. Stations are described by district, daily passengers, and station type. Connections are described by travel time and route type.

2. Node-Link Visualization

3. Node-Link Design Description

I encode district as node color, so geographic groups appear as color clusters. Daily passengers is encoded as node area: larger nodes represent busier stations. Station type is encoded as node shape: Local = circle, Transfer = square, Terminal = triangle. For links, travel time is encoded as line width: longer connections are wider. Route type is encoded as link color. Dragging lets me untangle overlapping links. Hovering a node highlights it and its direct neighbors while fading everything else, and tooltips provide exact station values.

4. Adjacency Matrix

5. Matrix Design Description

Rows and columns both represent stations. I order stations first by district (Central, North, South, East, West), then by station type (Terminal, Transfer, Local), and finally by daily passengers. This creates district blocks along the diagonal. A filled cell means a direct connection. Cell color shows route type, and cell opacity shows travel time: darker cells indicate longer travel times. Row and column labels are colored by district.
