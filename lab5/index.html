1 Dataset Description

This dataset represents a synthetic urban transit network with 50 stations and 50 direct undirected connections. Stations are described by district, daily passengers, and station type. Connections are described by travel time and route type.

2 Node-Link Visualization

Drag stations to inspect overlapping connections. Hover over a station to highlight its direct neighbors and view its exact values.

3 Node-Link Design Description

I encode district with node color so stations from the same administrative area can be compared visually. I encode daily passengers with node area because larger symbols make busier stations easier to notice. I encode station type with node shape so Local, Transfer, and Terminal stations remain distinguishable even when their districts are similar. For links, travel time is shown with line width so longer direct connections stand out, while route type is shown with link color so different transit services can be followed across the network. Dragging helps reduce overlap and inspect local structure. Hover highlighting focuses attention on one station and its direct neighbors. Tooltips provide exact station values when the visual encodings are not precise enough.

4 Adjacency Matrix

5 Matrix Design Description

Rows and columns both represent stations. Stations are ordered first by district, then by station type, and finally by daily passengers. This ordering creates visible district blocks and makes connections within and between districts easier to compare. A filled cell means that the two stations have a direct connection. Cell color represents route type and cell opacity represents travel time. Row and column labels use district colors so the district grouping remains visible. This matrix preserves connection structure while reducing the visual crossing that can occur in a node-link diagram.
