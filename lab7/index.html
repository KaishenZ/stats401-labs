Day 1 —

Assignment Part E — Temporal Network Questions

Answers below are observational readings of the animation above. Use Play / the time slider to verify each claim on your own dataset.

1. How does overall network connectivity change across the 60 days?

The overall connectivity changes substantially over the 60 days rather than following a consistent upward or downward trend. The number of active links ranges from 3 to 10, while the number of active companies ranges from 6 to 12. Some days have many active relationships and companies, while other days contain only a few connections. The network therefore becomes more connected and less connected at different points in time.

The animation makes these changes visible because links appear and disappear as the selected day changes. The summary panel also provides the exact number of active links and companies for each day.

2. Which companies become more central or commercially active over time?

The node size represents the total transaction volume for each company on a given day, so larger nodes indicate higher commercial activity. Fusion Electronics is one of the most active companies throughout the dataset and has particularly high transaction volume during the middle part of the 60-day period. Ion Systems becomes more prominent later in the period, especially during the final 20 days. Cedar Retail also becomes more active during the later part of the dataset.

These changes show that commercial activity is not evenly distributed across companies. Different companies become more prominent at different points in time, which can be observed through changes in node size.

3. Are there periods when the network consists of relatively separate clusters?

Yes. The network contains multiple disconnected components on several days. Depending on the selected day, the active network can contain two, three, or four separate components. For example, the network is particularly fragmented at the beginning of the period, while other days contain a larger connected component with only a few smaller components.

As new relationships appear, previously separate groups can become connected. This makes the temporal animation useful for observing how the structure of the network changes over time.

4. Which commercial relationships appear, disappear, or become stronger over time?

Many commercial relationships are temporary and appear only on certain days. The dataset also contains recurring relationships that appear repeatedly throughout the 60-day period. For example, several company pairs occur on a regular pattern across multiple weeks rather than remaining active continuously.

The strength of a relationship can also change because link width represents transaction amount. A wider link indicates a larger transaction amount on that day, while a thinner link represents a smaller amount. Therefore, changes in link width provide a way to identify relationships whose transaction activity increases or decreases over time. The tooltip can be used to examine the exact transaction amount and count for a selected relationship.

5. Does the network become more or less cross-regional over time?

The network does not show a consistent increase or decrease in cross-regional activity. The proportion of cross-regional transactions varies considerably across the 60 days, ranging from 0% on some days to 87.5% on others. The average proportion is also fairly similar across the three 20-day periods, although the final 20 days show somewhat more cross-regional activity than the first two periods.

This suggests that cross-regional connectivity changes with the activity of the network rather than following a simple long-term trend. The cross-region statistic and the regional outlines on the nodes make these changes easier to identify during the animation.
